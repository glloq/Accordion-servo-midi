Configurateur Accordion-servo-midi

Genere accordionV06/config.h : source d'air, actionneurs, MIDI, tables de notes.

Comment s'en servir

  1. Choisir la source d'air : seuls les reglages du systeme retenu restent affiches.
  2. Renseigner les actionneurs, le MIDI et les tables de notes.
  3. Corriger les erreurs signalees en bas de page — ce sont celles qui empechent le firmware de compiler, ou celles qu'un #if ne sait pas detecter.
  4. Telecharger config.h et le deposer dans accordionV06/, puis pio run ou compiler depuis l'IDE Arduino.

Page autonome : aucun reseau, aucune dependance. Le travail en cours est conserve dans le navigateur, et le bouton « Profil JSON » permet de l'archiver ou de le transmettre. Un config.h existant peut etre relu depuis la section Fichier genere.

Tables de notes

Une ligne par anche pilotee. Le numero de note MIDI est explicite : la disposition Stradella de la main gauche n'est pas chromatique, aucune continuite n'est supposee. Le debit d'air est relatif — une anche grave consomme davantage — et sert a calculer la demande envoyee a la source d'air.

Occupation des canaux PCA9685

Chaque case est un canal. La valve generale, le servo de soufflet et le canal ESC occupent un canal au meme titre qu'une anche : un conflit apparait en rouge.

Fichier genere

Remplacant complet de accordionV06/config.h. Les blocs des sources d'air non selectionnees y figurent aussi : changer de systeme plus tard ne demande pas de tout reecrire.

Le telechargement de config.h est desactive tant qu'une erreur subsiste. Le bouton « Copier » reste disponible pour inspecter le resultat.

Repartir d'une configuration existante

Coller un profil JSON ou un config.h deja ecrit. La relecture est tolerante : ce qui n'est pas reconnu garde sa valeur par defaut, et le compte de ce qui a ete lu est affiche.
